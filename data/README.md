# Dataset attribution

`ai4i2020.csv` is the unchanged AI4I 2020 Predictive Maintenance Dataset (2020),
UCI Machine Learning Repository, DOI: https://doi.org/10.24432/C5HS5C.

Source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

License: Creative Commons Attribution 4.0 International
(https://creativecommons.org/licenses/by/4.0/).
10,000 synthetic records. These are not measurements from an actual factory.
The downloaded CSV's SHA-256 is recorded by training in `reports/metrics.json`.
The five failure indicators are excluded from inference and used only in error analysis.
`predictions.sqlite3` is generated locally and should not be committed or shared.
